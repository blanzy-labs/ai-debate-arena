## Scope And Limitations

- No database.
- No telemetry.
- No login/auth.
- No saved debate or prompt history.
- Real debates may send user input and generated debate context to external providers.
- AI Debate Arena does not browse the web or verify facts.
- Markdown export is browser-side Markdown export from the current in-memory result.
